EVORA SUSTAINA - Backend Architecture & SQL Schema

// 1. SQL Database Relational Schema (PostgreSQL/MySQL) 
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    full_name VARCHAR(100) NOT NULL,
    email VARCHAR(150) UNIQUE NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE products (
    id SERIAL PRIMARY KEY,
    title VARCHAR(200) NOT NULL,
    category VARCHAR(50) NOT NULL,
    price DECIMAL(10,2) NOT NULL,
    rating DECIMAL(2,1) DEFAULT 5.0,
    eco_impact_desc TEXT,
    image_url TEXT,
    stock INT DEFAULT 100
);

CREATE TABLE orders (
    id VARCHAR(50) PRIMARY KEY,
    user_email VARCHAR(150) NOT NULL,
    subtotal DECIMAL(10,2) NOT NULL,
    tax DECIMAL(10,2) NOT NULL,
    shipping DECIMAL(10,2) NOT NULL,
    grand_total DECIMAL(10,2) NOT NULL,
    payment_method VARCHAR(20) NOT NULL,
    status VARCHAR(30) DEFAULT 'PROCESSING',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
// 2. REST API Endpoints (Node.js Express / Python Flask)

GET /api/v1/products - Fetch catalog with filtering & sorting query parameters

GET /api/v1/products/:id - Fetch single product details

POST /api/v1/cart/checkout - Process order payment & decrease inventory stock

POST /api/v1/newsletter - Store eco newsletter subscriber email

// 3. Shopify & WooCommerce API Webhook Hooks Ready

This architecture maps directly to Shopify GraphQL Storefront API `checkoutCreate` and WooCommerce REST v3 order creation schemas.
